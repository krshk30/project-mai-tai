A stale/above-cap/session/control/budget refusal therefore passes the current quantity/limit to MOMSTUCK2 settlement. This bound is proposed source behavior, not measured optimized latency.

It rechecks original signal/quote/session/current control stamp, refuses a changed rounded price/qty, and checks the actual serialized payload equals the committed request. The permit marker is excluded only from pure non-price comparison; it is never deleted/mutated. Any final assertion refusal remains outside MOMSTUCK2 settlement; existing unknown/client-report ownership and cancellation/reconciliation continue, with no resubmit.

Other orders have no bound ContextVar. Schwab avoids body parsing when inactive; Webull returns before price conversion when inactive.
