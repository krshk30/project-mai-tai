## Additional Design Edges To Resolve Before A Fix

1. Decimal arithmetic needs a stated input representation. Existing metadata
   is four-decimal but the live ATR line is a float. Unconditionally applying
   Decimal ceiling to `str(4.510000001)` produces 4.52, contrary to the card's
   noise example. Conversely, rounding all mathematical rule prices to four
   decimals before ceiling can round a genuine just-above-tick price down.
   A blanket epsilon or new tolerance is not introduced by this assessment.
   The user has been asked which representation defines the canonical price:
   existing four-decimal strategy price, or full-precision ATR calculation.
   The runtime build waits for this definition; it is not labelled queued or
   safe to implement by guessing.
2. Restarted old orders cannot be re-labelled as being on the new tick. Their
   actual wire stop must be proven/read; any rounding migration must not cancel,
   replace, change quantity or create a second buy by itself. RPG feedback
   currently restores the metadata stop, which may differ from old wire price.
3. The boundary rules differ in representation: Schwab formats four decimals
   at exactly 1.00, Webull uses two. Numeric 1.00 is the same stop; preserve each
   adapter's representation and re-evaluate the tick when a sub-dollar ceiling
   lands at 1.00. Both current one-tick pair lifts must remain.
4. NFQ shape/no-chase and software cap readers currently calculate their own
   caps from the trigger, while sizing uses broker rounding. A new trigger
   alone is not proof that every cap/limit check uses the final wire pair.
