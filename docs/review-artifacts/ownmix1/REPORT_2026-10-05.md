quantity to equal the managed quantity. The parent Codex audit identified that as extra
scope. It was removed before commit/push, together with all `working_quantities` broker
plumbing and quantity-coverage tests. The Schwab adapter has no resulting code change.

but reads only the managed row's exact owned parent. There is no symbol-wide ownership set.

fixes it nor claims that working legs fully cover a scaled managed quantity.

Full-close exit-fill quantity proof is separate: a child must match the bound entry's
parent/pair, symbol and current managed quantity before attribution/close. Quantity alone
never establishes ownership. Invalid quantities fail closed without placing the ladder
into an unrecorded-child hold. No trading window, sizing, target, stop, scale, gate, timeout,
or flag was added or widened. No new OWNMIX feature flag: deployed ownership checks are
active wherever the existing paths run, on both accounts and AM/RTH/PM.
