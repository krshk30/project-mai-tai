L3 metrics-only compatibility extension -- local, no operational approval

Wire JSON metrics version1 and stream suffixmomentum-warning-metrics unchanged.
G2 wire native shape retained:source=momentum-paper,strategy_code/logical_id,
observed_decision_ns,signals array (max2), lifecycle payload summary or sparse
FILLED/EXITED delta. G3 maps this bounded native shape only after validating the
original source epoch, UTC observation and read timestamp; no cached-epoch guess.

Canonical fields:ledger=exact strategy_code; window_seconds from the fixed
30/60 ledger map; lineage_id=exact logical_id. Summary identity fields must
match where present; DETECTED requires all identity fields. Candidate packets
with signals=[] are not BUY decisions and create no paper entry/comparison.
Two ledger expansion cap, bounded payload/read and stable hash child Redis-ID
dedup retained. No new network/client/subscription/cap policy introduced.

Warning observeddecision_ns comes from original payload completion capture,
never the later FILLED/EXITED callback. Sparse updates can retain known fields
only from the exact same epoch/ledger/logical-ID detail; they are not counted
as additional entry signals. Snapshot detection capture comes from its actual
decision callback. Missing capture with no prior DETECTED remains UNKNOWN.

Signal provenance:
- Qualifying close with raw s/e1000-exclusive bounds ->bucket_sufficient.
  No exact high/low/close SIP timestamp manufactured.
- Real DETECTED callback SIPns, matching the stored detection millisecond,
  ->raw_exact; keep original ns. Later fill callback is NOT the signal.
- Native historical integer SIPms ->integer_ms_bounds, [ms,ms+1) expressed
  in UTCns. These bounds are not exact SIPns or bucket-low timestamps.
Missing clock_skew_bound/status remains UNKNOWN, not clock-qualified latency.

entry_ns/exit_ns use real callback SIPns only where the emitted FILLED/EXITED
print matches the stored print millisecond. Missing historical exactns remains
UNKNOWN. Companion CSV adds entry/exit_timestamp_precision plus
entry/exit_sip_start_ns,end_ns. Integer-ms model timestamps remain labelled;
delayed target confirmation cannot become the target print's exact timestamp.
No nearest-stock/time pairing: absent comparison_id keeps COUNTERPART_UNKNOWN.
No invented subscriber ACK, cap_status, complete coverage or missing counts=0.

Source repair: Snapshot FILLED/EXITED wire packets now carry the already observed
warning gateway epoch, like Snapshot DETECTED and warning lifecycle packets.
If epoch is absent, G3 still refuses; it cannot borrow the latest gateway sample.
This is metrics-only; strategy detection/fill/exit/OMS/provider paths unchanged.

Remaining observability gaps: native consumer_sample has owned/shared symbol
counts and transport status, not documented warning_count/subscribed_count;
those old collector fields remain UNKNOWN pending exact counter semantics.
Clock-driven paper advance/finalization persistence does not yet emit every
terminal lifecycle metric. W4 completeness therefore not asserted by this fix.
These are local integration followups, not a reason to fabricate missing values.
